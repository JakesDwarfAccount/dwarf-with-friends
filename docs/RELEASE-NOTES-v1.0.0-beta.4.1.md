# Dwarf With Friends v1.0.0-beta.4.1

A small follow-up to beta 4 that fixes a bunch of interface regressions and other small stuff.

- Panels across the mod look like Dwarf Fortress again. Text that was clipped or cut off now fits,
  controls line up, and everything uses the game's font.
- Lots of smaller fixes and cleanup behind the scenes.

Beta 4.1 needs the same Dwarf Fortress 0.53.16 with DFHack 53.16-r1 as beta 4.
